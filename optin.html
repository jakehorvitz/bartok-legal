Bartok Notifications — SMS Opt-In Workflow

Effective date: August 28, 2026

Bartok Notifications is a personal SMS notification program operated by Jake Horvitz (sole proprietor). It sends account notifications to the program owner and to individuals who have expressly opted in: pending approval items, daily digests, and status replies to commands the user texts first. This page documents the complete opt-in workflow. There is exactly one opt-in path.

The only opt-in path: interactive setup consent

Bartok is self-hosted software. A person is enrolled only by running the interactive setup program on their own computer. During setup, the person:

  1. Enters their own mobile phone number.
  2. Is shown the full consent notice reproduced below, including program name, message frequency, rate disclosure, HELP/STOP instructions, and links to the privacy policy and terms.
  3. Must actively type the word YES to consent. Nothing is pre-checked or pre-filled; any other input aborts the setup and no number is enrolled.

Opting out and help

Reply STOP to any message to stop receiving messages at any time. Reply HELP for help. Consent is never a condition of any purchase, and opt-in data is never shared with third parties (see the privacy policy).
