How the opt-in works, start to finish

  1. The recipient reads the call to action above, either on this page or as printed by the setup program (which prints the same text and links to this page).
  2. He texts START from his own mobile phone to +1 805-866-0420. That text is the consent. Nothing is pre-selected, pre-filled, or defaulted: there is no web form, checkbox, or purchase involved.
  3. He immediately receives this confirmation message: 
    Bartok Notifications: you are opted in. Msg freq varies, msg and data rates may apply. Reply HELP for help, STOP to cancel.
  4. Only after that START has been received and recorded does the software send anything. The sending function refuses every message until an opt-in is on record, and refuses again after a STOP until a new START arrives. This is enforced in the software (bartok/consent.py), not only described here.

This is the only opt-in method. Because the program is single-recipient and the only number that can be enrolled is the sole proprietor's own verified mobile number, there is no public sign-up form and no other way for any number to be enrolled. A START from any other number enrolls nothing.
