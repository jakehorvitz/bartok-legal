Bartok Notifications

Effective date: August 31, 2026

Bartok Notifications is a personal, single-recipient SMS notification program operated by Jake Horvitz, a sole proprietor based in Santa Barbara, California.

What the program does

Bartok is self-hosted software that runs on the operator's own machine and assists him with his own business administration. When it needs a decision, it sends a text message to the operator's own mobile phone so he can approve or decline an item away from his desk. Specifically it sends:

  • Approval requests — a short description of a pending item and a reply code to approve or decline it.
  • Daily digests — a once-daily summary of items still awaiting a decision.
  • Status replies — responses to commands the operator texts to the number first.

Who receives these messages. Only one person: the operator himself, at his own mobile number. The software has no recipient parameter, so his configured number is the only destination a message can be sent to. The program has no customers, subscribers, or third-party recipients, and it sends no marketing, promotional, or third-party content of any kind.
